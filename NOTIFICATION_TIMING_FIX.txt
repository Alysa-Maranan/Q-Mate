HOW IT WORKS
------------

Browser continuously checks every 2 seconds:

Check #1: active: false → No feeding
Check #2: active: false → No feeding
Check #3: active: true  → Feeding started! (mark as active)
Check #4: active: true  → Still feeding... (wait)
Check #5: active: true  → Still feeding... (wait)
Check #6: active: false → Feeding done! (was active, now inactive)
                        → ✅ SHOW NOTIFICATION

Key Logic:
- Track previous state (lastCheckedActive)
- If was active (true) and now inactive (false)
  → Feeding just completed
  → Show notification
