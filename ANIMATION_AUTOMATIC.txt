TECHNICAL DETAILS:

Continuous Polling:
- Browser checks /api/feeder/animation every 2 seconds
- Kapag may active feeding, lalabas ang notification
- Kapag na-delete na ang animation file, mawawala ang animation

Animation Flow:
1. Schedule triggers → servo_bridge creates animation_trigger.json
2. Browser detects file → shows notification modal
3. User clicks OK → shows animation
4. Servo completes → servo_bridge deletes animation_trigger.json
5. Browser detects deletion → hides animation
6. Page reloads → updated feed history

TROUBLESHOOTING:

❌ Hindi lumalabas ang animation?
   → Check kung running ang servo_bridge: check_servo_bridge.bat
   → Check browser console (F12) for errors
   → Check kung may animation_trigger.json sa storage/logs/

   → Hintayin 5 seconds

   → Kung stuck, i-refresh ang page (F5)

❌ Walang notification modal?

   → Check browser console for errors
