PAANO GUMAGANA
--------------

MANUAL FEED:
1. Click "Feed Now"
2. Animation appears
3. Browser polls /api/feeder/animation every 500ms
4. Servo bridge deletes file after duration
5. Browser detects deletion
6. Animation hides after 1 second
7. Page reloads

SCHEDULED FEED:
1. Browser checks every 2 seconds
2. Notification appears when feeding time arrives
3. Click "OK, Got it"
4. Animation appears
5. Same as manual feed from step 3

TROUBLESHOOTING
---------------

❌ Animation hindi lumalabas?
   → Run: check_servo_bridge.bat
   → Check browser console (F12)
   → Restart: start_feeder_system.bat

❌ Animation hindi nawawala?
   → Check browser console for errors
   → Check if animation_trigger.json was deleted
   → Run: test_animation.bat
   → See: ANIMATION_TROUBLESHOOTING.txt

❌ Manual feed walang animation?
   → Check browser console
   → Should see: [Manual Feed] Starting animation...
   → If not, check if servo bridge is running
