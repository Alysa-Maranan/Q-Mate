═══════════════════════════════════════════════════════════════

TROUBLESHOOTING:

❌ Hindi lumalabas ang animation?
   → Run: check_servo_bridge.bat
   → Kung hindi running: start_feeder_system.bat

❌ Hindi nawawala ang animation?
   → Hintayin 5 seconds
   → Kung hindi pa rin: Press F5 (refresh)

❌ Hindi umaandar ang servo?
   → Check USB connection
   → Check COM port sa Device Manager
   → Restart: stop_feeder_system.bat then start_feeder_system.bat

❌ Hindi nag-trigger ang schedule?
   → Check kung running ang servo bridge
   → Check kung running ang scheduler
   → Check ang time (dapat exact match)
